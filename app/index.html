Master in MXF or MOV?

Pull the mix out as a WAV with ffmpeg first. Interleaved audio track:

ffmpeg -i master.mxf -map 0:a:0 -c:a pcm_s24le mix.wav

Six mono tracks making up a 5.1 mix:

ffmpeg -i master.mxf -filter_complex "[0:a:0][0:a:1][0:a:2][0:a:3][0:a:4][0:a:5]amerge=inputs=6" -c:a pcm_s24le mix51.wav

Match a QC report

Type the integrated loudness a QC platform reported for this file. Gatecheck finds which measurement method reproduces it, including common channel-mapping mistakes.

    Calibration

    Offsets learned from QC reports you have matched. After a few files, Gatecheck predicts what each platform will report before you deliver. Saved in this browser.

    Correct to spec

    A static gain change to hit the selected spec's target with its own gate. True peak is checked after the gain.

    Report

    Every reading, every spec verdict and the QC match for this file, as a CSV for the ticket or the QC log.

    The dialogue detector is Gatecheck's own (speech-band energy, syllabic modulation and pauses). Commercial detectors differ, so dialogue-gated values can sit a few tenths of an LU away from a QC platform's. Use calibration to close that gap.
